# NBA 球隊勝率預測（進階指標 × 機器學習）

本專案以 **NBA 球隊 × 球季** 為分析單位，使用多種進階指標預測球隊的 **勝率（Win Rate）**。  
這個 repo 的重點不只是「模型準不準」，而是完整展示一套研究流程：包含資料整理、避免資料洩漏的前處理、特徵篩選、多模型比較，以及 SHAP 解釋分析。

---

## 專案在做什麼？

這個專案想回答的核心問題是：

> 球隊層級的多維進階指標，能不能有效預測 NBA 球季勝率？

因此，這個 repo 的重點不是單純丟資料進模型，而是把整個分析流程設計成一套可重複執行、可檢查、可解釋的 pipeline。

## 預測目標

- **目標變數**：`Win Rate`
- 若使用 `win_rate` 命名，程式也可自動對應
- **驗證方式**：
  - `year_holdout`
  - `rolling_year`
- 驗證邏輯以 **年度切分** 為核心，目的在於降低時間資訊洩漏
- **模型流程**：
  - 前處理與共線性篩選
  - `LassoCV`
  - `ElasticNetCV`
  - `XGBoost`（搭配 Grid Search）
  - SHAP 解釋與視覺化輸出

## 研究設計摘要

### 1. 分析單位
每一筆資料代表一個 **球隊 × 球季** 的組合。

### 2. 資料整理方式
每季資料整理成 `YYYY_metrics.csv`，再合併成跨年度 panel data。  
檔名中的年份會轉成 `year` 欄位，供後續時間切分使用。

### 3. 特徵設計
- 目標欄位為 `Win Rate`
- 其他數值型進階指標皆視為候選特徵

### 4. 方法流程
模型訓練前，先進行：
- 缺值處理
- 標準化
- 低變異特徵移除
- 共線性篩選

接著比較三條模型路徑：
- **LassoCV**
- **ElasticNetCV**
- **XGBoost**

### 5. 驗證方式
所有前處理與特徵選擇都只在 **訓練期間** 擬合，再套用到測試資料，避免測試年份資訊回流到訓練過程，降低資料洩漏風險。

### 6. 結果解釋
除了模型分數外，也保留：
- 係數圖
- 殘差圖
- 特徵縮減圖
- SHAP summary
- rolling backtest 圖表

因此這個專案重視的不只是預測表現，也包含模型為何做出這些預測。

## 公開版示範結果摘要

以目前公開版示範資料為例：

- **Lasso**
  - Train `R^2 = 0.9058`
  - Test `R^2 = 0.8420`
- **Elastic Net**
  - Train `R^2 = 0.9058`
  - Test `R^2 = 0.8420`
- **XGBoost**
  - Train `R^2 = 0.9856`
  - Test `R^2 = 0.7903`

這組結果的重點不是單看誰的訓練分數最高，而是比較 **訓練表現與測試表現之間的落差**。  
在這份示範資料中，**Lasso 與 Elastic Net 的測試表現較穩定，且泛化能力優於 XGBoost**；相對地，XGBoost 在訓練集表現非常高，但在測試集下降較多，代表它在目前資料條件下可能更容易出現 overfitting。

> 上述數值僅代表公開版 **合成資料** 的示範輸出，  
> **不代表原始研究資料的正式結論。**
